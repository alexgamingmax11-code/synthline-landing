## Your Path to First Client

```
Week 1 → Build lead list (50 businesses)
Week 2 → Send 150 cold emails, make 50 calls
Week 3 → Follow up, book demos
Week 4 → Close first client ($299+/mo)
```

---

## Workflow (Daily)

### Step 1: Find 10 new leads (30 min)
Open `lead_collector.py generate` URLs → search Google Maps → copy into CSV/Google Sheets

### Step 2: Send 30 emails (20 min)
Use templates below → customize industry + business name → send

### Step 3: Make 10 calls (30 min)
Use phone scripts → dial → log result in tracker

### Step 4: Follow up (15 min)
Check previous outreach → send follow-up emails → log responses
